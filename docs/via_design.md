# 差分过孔设计 (85Ω) — 参数表

## 目标
85Ω 差分过孔, |S11| < -15dB @12.9GHz, TDR 85Ω±10%

## 推荐参数 (8层, 1.6mm 板)

| 参数 | 值 | 说明 |
|------|-----|------|
| 钻孔直径 | 8-10 mil | 越小越好(减电容), 但受工艺限制 |
| 过孔焊盘 | 14-16 mil | 比钻孔大 6mil |
| anti-pad 直径 | **28-30 mil** | ★ 关键! 决定过孔阻抗 |
| 差分孔间距 | 2×线间距 | 保持耦合; 85Ω外→内部100Ω |
| GND 伴随过孔 | 每对 4 个 | 四角, 距信号孔 <25mil |
| 背钻 stub | **<10 mil** | ★ 25G 必须 |

## anti-pad vs 阻抗 (估算)
```
anti-pad 20mil → ~96Ω    (太高)
anti-pad 24mil → ~92Ω
anti-pad 28mil → ~87Ω    ✅
anti-pad 30mil → ~85Ω    ✅ 目标
anti-pad 32mil → ~83Ω    ✅
anti-pad 36mil → ~78Ω
anti-pad 40mil → ~74Ω    (太低)
```

## 布局要点
1. GND 伴随过孔紧邻 (提供回流, 稳定阻抗)
2. anti-pad 不在相邻层交叠 (避免层间耦合)
3. 差分对两个过孔对称 (等长对称)
4. 背钻后 stub <10mil (否则相位失真)
5. 过孔焊盘上若需测试点, 用 <0.5mm

## 验证方式
- 3D 全波仿真 (openEMS): 建 8 层过孔 + anti-pad + GND 孔
- 或 TDR 实测 (打样后用 TDR 探头)
- 目标: 过孔段阻抗 85Ω±10%, S11 < -15dB @12.9GHz
